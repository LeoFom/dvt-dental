# DVT Denta

Адаптивний сайт стоматології DVT Denta в Івано-Франківську. React + TypeScript + Tailwind CSS + Vite.

## Локальний запуск

Потрібні Node.js 24 і pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Перевірка production-збірки:

```sh
pnpm build
pnpm preview
```

## Vercel

Імпортуйте репозиторій `LeoFom/dvt-dental` у Vercel. Коренева папка: корінь репозиторію. Фреймворк: Vite. Налаштування встановлення, збірки та вихідної папки визначені в `vercel.json`. Змінні середовища для цього SPA не потрібні.

Після підключення Git integration нові коміти автоматично запускають деплой. Гілка production визначається в налаштуваннях проєкту Vercel.

## Контент і компоненти

- `src/content.ts`: адреса, телефон, послуги й FAQ.
- `src/main.tsx`: секції сторінки та переходи до форми.
- `src/ContactRequestForm.tsx`: коротка форма звернення, перевірка телефону, надсилання й стани очікування, успіху та помилки.
- `shared/contact.js`: спільна нормалізація телефону для браузера й сервера.
- `api/contact.js`: серверна Vercel Function для доставки заявки в Telegram.
- `src/styles.css`: дизайн токени Tailwind та адаптивність.
- `public/images/`: оптимізовані зображення.
- `public/fonts/`: локальний Unbounded Medium для основних заголовків; ліцензія SIL Open Font License у `public/fonts/OFL.txt`. Основний текст і поля використовують системний шрифт.

Форма: необов’язкове ім’я, обов’язковий телефон і кнопка «Надіслати заявку». Браузер і сервер перевіряють номер. Під час запиту кнопка й поля блокуються; успіх показується тільки після підтвердження Telegram та перевірки отримувача. При помилці дані залишаються в полях, доступна повторна спроба або телефон. Введені значення не потрапляють у URL чи localStorage і не записуються в логи. Перед закриттям сторінки з ненадісланими даними браузер запитує підтвердження; після успіху попередження знімається.

Серверні змінні Vercel: `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`. Обидві зберігаються як Secrets, без префікса `VITE_`. Встановлюйте їх у середовищі/гілці цільового розгортання до деплою. Вихідні секрети не входять до репозиторію чи архіву. Боту достатньо мати відкритий чат з отримувачем; webhook для вихідних повідомлень не потрібен.

API приймає лише JSON POST, обмежує тіло до 2 КБ, відхиляє інший Origin, некоректні поля й заповнену honeypot-пастку. Telegram отримує лише ім’я, нормалізований телефон, час і технічний ідентифікатор заявки. У повідомленні немає HTML/Markdown parse mode. Таймаут Telegram — 10 секунд, функції — 15 секунд; автоматичних повторів надсилання немає.

`pnpm test` перевіряє API без реальних повідомлень. `pnpm dev`/`pnpm preview` запускають лише Vite; `/api/contact` обслуговується Vercel Functions у розгортанні (або Vercel CLI локально). Автономний HTML призначений для перегляду; робоча доставка потребує сайту з API. Аналітика не підключена.

Поточна версія містить `noindex, nofollow`. Перед індексацією потрібно підтвердити бізнес-дані, права на фото й налаштувати основний домен та SEO-метадані.

## Автономний HTML

Після збірки можна створити автономний файл із вбудованими ресурсами:

```sh
node scripts/export-preview.mjs
```

За замовчуванням він записується як `../DVT-Denta-preview.html`. Інший шлях можна передати першим аргументом.
