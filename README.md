# DVT Denta

Адаптивний сайт стоматології DVT Denta в Івано-Франківську. React + TypeScript + Tailwind CSS + Vite.

## Локальний запуск

Потрібні Node.js 24 і pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Перевірка production-збірки:

```sh
pnpm build
pnpm preview
```

## Vercel

Імпортуйте репозиторій `LeoFom/dvt-dental` у Vercel. Коренева папка: корінь репозиторію. Фреймворк: Vite. Налаштування встановлення, збірки та вихідної папки визначені в `vercel.json`. Для доставки заявок потрібні серверні змінні `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`; вони не повинні мати префікс `VITE_` або потрапляти в репозиторій.

Після підключення Git integration нові коміти автоматично запускають деплой. Гілка production визначається в налаштуваннях проєкту Vercel.

## Контент і компоненти

- `src/content.ts`: адреса, телефон і FAQ.
- `src/main.tsx`: секції сторінки, інтерактивні картки й кнопки відкриття форми.
- `src/HeroVideo.tsx`: відео програється один раз і залишається на кінцевому кадрі. До 600px спочатку показується портрет; після секунди відтворення він зсувається праворуч, а текст і CTA з’являються послідовно. На десктопі анімується лише поява тексту. Reduced motion показує кінцевий кадр і весь текст одразу; заблоковане/невдале відтворення та затримка завантаження не блокують доступ до CTA.
- Поточний ролик: `public/media/hero-smile-v2.mp4`, постери `public/images/hero-video-v2-first.webp` і `hero-video-v2-last.webp`. Попередні `hero-smile.mp4`, `hero-video-first.webp` та `hero-video-last.webp` збережені для повернення до попереднього варіанта. Надісланий 17.11.2026 файл із суфіксом `(1)` має той самий SHA-256, що й початковий ролик; версія v2 є окремою копією того самого відео.
- `src/ContactRequestModal.tsx`: спільне модальне вікно та форма, збереження чернетки, перевірка полів і стани надсилання.
- `shared/services.js`: єдине джерело назв, ідентифікаторів та описів напрямів лікування.
- `shared/contact.js`: нормалізація телефону й дозволені категорії для браузера та сервера.
- `api/contact.js`: серверна Vercel Function для доставки заявки в Telegram.
- `server/telegram-message.js`: оформлення повідомлення для керівника та кнопка копіювання номера.
- `src/styles.css`: дизайн токени Tailwind та адаптивність.
- `public/images/`: оптимізовані зображення.
- `public/fonts/`: локальний Unbounded Medium для основних заголовків; ліцензія SIL Open Font License у `public/fonts/OFL.txt`. Основний текст і поля використовують системний шрифт.

Форма відкривається в одному нативному `dialog`: необов’язкове ім’я, обов’язковий телефон, напрям лікування та кнопка «Надіслати заявку». Початкова категорія — «Потрібна консультація»; користувач може надіслати заявку, не змінюючи її. П’ять карток підставляють свій напрям, шоста картка та загальні CTA — консультацію. Escape, хрестик і натискання на фон закривають вікно, зберігаючи введені дані в пам’яті сторінки. Після успіху нове відкриття починає нову заявку.

Браузер і сервер перевіряють номер. Під час запиту кнопка й поля блокуються; успіх показується тільки після підтвердження Telegram та перевірки отримувача. Закриття вікна під час надсилання не скасовує запит і не дозволяє створити дубль. При помилці дані залишаються в полях, доступна повторна спроба або телефон. Введені значення не потрапляють у URL чи localStorage і не записуються в логи. Перед закриттям сторінки з ненадісланими даними браузер запитує підтвердження; після успіху попередження знімається.

Серверні змінні Vercel: `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`. Обидві зберігаються як Secrets, без префікса `VITE_`. Встановлюйте їх у середовищі/гілці цільового розгортання до деплою. Вихідні секрети не входять до репозиторію чи архіву. Боту достатньо мати відкритий чат з отримувачем; webhook для вихідних повідомлень не потрібен.

API приймає лише JSON POST, обмежує тіло до 2 КБ, відхиляє інший Origin, некоректні поля й заповнену honeypot-пастку. Категорія передається ідентифікатором із дозволеного списку, а її назву сервер визначає сам. Відсутня категорія у старішому клієнті означає консультацію. Повідомлення Telegram має заголовок «🦷 Нова заявка на прийом», ім’я, нормалізований телефон, послугу, заклик узгодити дату й час та позначку часу отримання за Києвом. Кнопка «Скопіювати номер» копіює нормалізований телефон. HTML-форматування обмежене жирними підписами й курсивом; динамічні значення екрануються. Технічний ідентифікатор залишається в серверних логах і відповіді API, а в повідомленні для керівника не відображається. Заявка означає звернення для узгодження прийому. Таймаут Telegram — 10 секунд, функції — 15 секунд; автоматичних повторів надсилання немає.

`pnpm test` перевіряє API без реальних повідомлень. `pnpm dev`/`pnpm preview` запускають лише Vite; `/api/contact` обслуговується Vercel Functions у розгортанні (або Vercel CLI локально). Автономний HTML призначений для перегляду; робоча доставка потребує сайту з API. Аналітика не підключена.

Поточна версія містить `noindex, nofollow`. Перед індексацією потрібно підтвердити бізнес-дані, права на фото й налаштувати основний домен та SEO-метадані.

## Автономний HTML

Після збірки можна створити автономний файл із вбудованими ресурсами:

```sh
node scripts/export-preview.mjs
```

За замовчуванням він записується як `../DVT-Denta-preview.html`. Інший шлях можна передати першим аргументом.
